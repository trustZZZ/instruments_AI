# История версий

Все выпуски остаются доступными: ничего не удаляется, любую версию можно
скачать из [списка релизов](../../releases).

## 0.1.0 — 8 ноября 2026

Первая публичная версия.

**Добавлено**

- Выбор шаблона из библиотеки и создание проекта в выбранном каталоге.
- Проверка перед созданием: план и список замечаний, ничего не записывается
  на диск.
- Подстановка значений в шаблон и инициализация git-репозитория с первым
  коммитом.
- Открытие готового проекта в редакторе.
- Автоматическая проверка обновлений при запуске и установка новой версии
  по кнопке.
- Установщик для Windows и портативная сборка.
