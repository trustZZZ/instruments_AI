# История версий

Все выпуски остаются доступными: ничего не удаляется, любую версию можно
скачать из [списка релизов](../../releases).

## 0.1.3 — 8 ноября 2026

Обновление поверх запущенного приложения больше не прерывается.

**Исправлено**

- Установщик сам закрывает запущенную копию перед заменой файлов. Раньше
  обновление с версий до 0.1.2 могло остановиться с сообщением о том, что не
  удалось закрыть все приложения, а после установки открывалось второе окно.
- Установщик завершает только само приложение и не трогает посторонние
  процессы.

## 0.1.1 — 8 ноября 2026

**Изменено**

- Проверка обновлений включена по умолчанию: адрес сервера уже прописан,
  настраивать ничего не нужно.

**Исправлено**

- Журнал приложения на Windows записывался в кодировке системы и открывался
  нечитаемым текстом — теперь всегда UTF-8.

## 0.1.0 — 8 ноября 2026

Первая публичная версия.

**Добавлено**

- Выбор шаблона из библиотеки и создание проекта в выбранном каталоге.
- Проверка перед созданием: план и список замечаний, ничего не записывается
  на диск.
- Подстановка значений в шаблон и инициализация git-репозитория с первым
  коммитом.
- Открытие готового проекта в редакторе.
- Автоматическая проверка обновлений при запуске и установка новой версии
  по кнопке.
- Установщик для Windows и портативная сборка.
