# instruments

**Десктоп-приложение, которое создаёт новый проект из готового шаблона за несколько секунд.**

Вместо ручного копирования структуры, правки названий в документации и настройки
репозитория — выбираете шаблон, указываете имя и каталог, нажимаете «Создать».
Приложение делает остальное: разворачивает шаблон, подставляет значения в
документацию и конфигурацию, инициализирует git с первым коммитом и открывает
готовый проект в вашем редакторе.

## Возможности

- Библиотека шаблонов под разные типы проектов.
- Предварительная проверка: до записи на диск видно, что будет создано и какие
  есть замечания.
- Подстановка значений во все документы шаблона — без ручной правки.
- Инициализация git-репозитория с первым коммитом.
- Открытие созданного проекта в редакторе.
- Нативное окно на Windows, macOS и Linux.
- Автоматическая проверка обновлений.

## Как это работает

1. Открываете приложение.
2. Выбираете шаблон из библиотеки.
3. Указываете имя проекта и каталог.
4. Нажимаете «Проверить» — приложение показывает план создания и найденные
   проблемы.
5. Нажимаете «Создать» — получаете готовый проект с первым коммитом.
6. Окно закрывается, проект открыт в редакторе.

## Для кого

Для разработчиков и команд, которым важно начинать проекты одинаково: с
правильной структурой, актуальной документацией и без ручной рутины.
